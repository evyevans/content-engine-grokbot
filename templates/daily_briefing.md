# Platform delivery reference

There is no merged briefing. Each lead posts in its own group, with the ordered fields in master §9. Each copyable field has its own fenced block; caption+hashtags share one block. IG alt text is separate. YT title, description, optional tags and chapters are separate. No CTA IDs, pack labels, MODE or self-checks in the deliverable. Notes <15 words. Post window is required even when marked needs user selection.
