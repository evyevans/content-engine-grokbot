# TikTok playbook — configurable editorial defaults

The dated filename is retained for internal references. This is an engine format guide, not current platform policy or an algorithm guarantee. Master §§8–10 wins. Use the configured niche, audience, voice and real video; caption ≤300 chars excluding hashtags; 3–5 descriptive tags; search phrase early; one useful comment question.

Do not reuse a platform's last three CTAs or yesterday's exact hashtag set. Keep the shared on-screen text unchanged in SAME mode. Every pasteable field belongs in a fenced copy block. No internal numbers/logs in final user copy. Use the post windows supplied by the user or label needs user selection. No window is a proven best time without data. Related videos and special features require actual availability; do not assume account eligibility.

Current platform questions should be checked against official documentation: https://support.tiktok.com/. Record source and checked date in a research proposal. Existing formatting defaults remain until operator approval; no silent policy updates or fabricated trends.
