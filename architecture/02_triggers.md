# 02 — Triggers

checkin → four-line prompt once per local scheduled day; nudge/idea → only if no reply; user_reply/go → intake and dispatch; team_log → deduplicated CTA update and QC; five-minute missing team → coordinator fallback once; edit_request → team lead; selected comments/research/analytics → corresponding module. Use semantic trigger keys, not times embedded in names. Local dates follow the profile IANA zone. Second replies edit an existing summary unless the user explicitly requests an additional video. No-reply ends silently. Sources: daily loop, routine template, performance layer.

The resolved master configuration wins conflicts. This document describes the existing workflow, not additional agents or infrastructure.
