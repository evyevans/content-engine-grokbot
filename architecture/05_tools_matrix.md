# 05 — Tools and capabilities

Coordinator: group dispatch, direct lead messages, private state/logs, selected routines, optional research. Specialists: current summary and own pack only. Leads: final group delivery, direct log to coordinator, edits. IG Thumbnail: local renderer and file delivery, no group membership. All roles: no automatic social posting, login, spending or outreach. Runtime tool access depends on the host; prompt instructions are not technical permission switches. Missing capabilities are reported, not invented. Source: setup skill capability contract.
