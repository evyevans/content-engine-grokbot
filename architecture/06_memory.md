# 06 — Memory

Resolved master beats old memory. Role instructions are versioned by deployment manifest. Coordinator stores last three CTAs per platform; fourteen-day opener and taken-idea history; seven-day offered-idea history; local-date video/revision state. Specialists receive current summary and last-three CTAs. Start empty; missing logs mean none, not guessed history. Store operational logs under ignored .local/<instance>/logs, or a host-supported durable store selected during setup. Export locally before migration; never publish private logs.

The resolved master configuration wins conflicts. This document describes the existing workflow, not additional agents or infrastructure.
