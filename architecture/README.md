# Architecture — Grok Bot Content Engine

One coordinator → three platform groups, each with four ordered specialists → user-ready metadata in each group. A standalone IG Thumbnail bot handles covers. The user films and posts manually. Context and account bindings are configurable; runtime structure remains fixed.
