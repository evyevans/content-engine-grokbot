# 03 — Workflows

Check-in → one answer → intake → summary → three team groups → specialists 1/2/3/4 → one final block in each group → private logs → coordinator QC → one all-delivered message. SAME shares on-screen text; DIFFERENT routes separate summaries. Missing pack after ~60s can be supplied by the next specialist; missing team after five minutes uses coordinator fallback. Team edits repost changed fields only. Sources: agents/daily_briefing_orchestrator.md and agents/team_*.md.

The resolved master configuration wins conflicts. This document describes the existing workflow, not additional agents or infrastructure.
