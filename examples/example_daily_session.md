# Illustrative daily run — not deployment history

The user profile supplies the niche, audience and pillars. This neutral example explains a checklist video.

User: “Today I’ll show the three checks I make before starting a project. Same video everywhere; post tomorrow.”

Coordinator posts the following in each team group:
```text
TONIGHT'S VIDEO SUMMARY
Date: [today in configured zone]
Video mode: SAME
Pillar: [selected configured pillar]
The user demonstrates three preparation checks and explains why each prevents rework.
• Hook: Three checks before you start.
• Payoff: A repeatable preparation checklist.
• Key emotion: Confidence
• Target viewer: [configured audience]
• Search phrase: project preparation checklist
• Shared on-screen text: Three checks before you start.
• Post timing: TOMORROW [local date]
• Last 3 CTAs: TikTok none · IG none · YT none
• Platform notes: Original footage; no related long-form video.
MODE: BUILD · BOTTLENECK: input
```
Each team works in order. Leads deliver in their own groups, then log privately. After QC and all three logs, the coordinator sends one all-delivered line. This example is not a claim the user made such a video.
